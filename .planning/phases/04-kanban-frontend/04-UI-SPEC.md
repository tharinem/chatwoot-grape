## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between icon and text in cards |
| sm | 8px | Compact element spacing, card internal padding, gap between filter chips |
| md | 16px | Default element spacing, column header padding, card margin-bottom |
| lg | 24px | Section padding, board top bar padding, slide panel internal padding |
| xl | 32px | Column gaps (horizontal gap between Kanban columns) |
| 2xl | 48px | Board outer horizontal padding |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Kanban column width: 280px fixed (not a spacing token, a layout dimension)
- Drag ghost card offset: 8px shadow offset
- Touch/click target minimum: 32px (h-8) for icon-only buttons in column headers

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm font-normal` |
| Label | 12px | 460 | 1.4 | `text-xs font-[460]` |
| Heading | 16px | 600 (semibold) | 1.25 | `text-base font-semibold` |
| Display | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold` |

**Usage mapping:**
- **Display:** Board title / page header only
- **Heading:** Column (stage) titles, slide panel card title, form section headings
- **Body:** Card contact name, filter labels, form field values, toast messages
- **Label:** Card metadata (channel, date, agent), column card count, helper text

**Source:** Chatwoot uses custom font weights 420/440/460/520 (see `tailwind.config.js`). We use 460 for labels (slightly heavier than normal) and standard 600 for headings. DM Sans is the primary font per D-13.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-n-background` / `bg-n-slate-1` | Page background, board surface |
| Secondary (30%) | `bg-n-slate-2` / `bg-n-slate-3` | Column backgrounds, card surfaces, filter bar background |
| Accent (10%) | `bg-n-brand` (#7B5EA7) | Primary CTA buttons, "Atribuidos a mim" active state, stage color picker default |
| Destructive | `bg-n-ruby-9` / `text-n-ruby-11` | Delete stage button, delete card action, error toasts |

**Accent reserved for:**
1. "Novo card" primary CTA button (solid blue variant per Chatwoot Button pattern)
2. "Atribuidos a mim" quick-filter active indicator
3. Stage color accent bar (top border of each column, admin-configurable per D-12)
4. Drag drop-zone highlight border

**Neutral palette usage (n-slate scale):**
- `text-n-slate-12` — Primary text (contact names, headings)
- `text-n-slate-11` — Secondary text (labels, metadata, placeholders)
- `text-n-slate-9` — Tertiary/disabled text
- `border-n-weak` — Card borders, column dividers
- `border-n-strong` — Focused input borders, active column header
- `bg-n-alpha-2` — Hover states on ghost buttons and cards

**Dark mode:** Automatically handled via `darkMode: 'class'` on the Tailwind config. All color references use CSS vars with `n.` prefix which resolve correctly in both modes. No separate dark palette needed.

**Source:** D-12, D-13 from CONTEXT.md; `theme/colors.js` n-palette; Button.vue STYLE_CONFIG.

## Interaction Contracts

### Drag-and-Drop (D-04, D-05)

| Behavior | Specification |
|----------|---------------|
| Drag start | Card lifts with `shadow-lg`, opacity reduced to 0.9, scale 1.02 |
| Drag over column | Column background shifts to `bg-n-blue-3/50`, border becomes `border-n-blue-7` dashed |
| Card displacement | Existing cards animate with 200ms ease-out to open a 72px gap at drop position |
| Drop | Card snaps to position, shadow returns to `shadow-sm`, API PATCH fires immediately |
| Drop failure | Card animates back to origin (300ms ease-in-out), error toast appears |
| Optimistic update | UI updates instantly on drop; on API error, rollback to previous state |

### Slide Panel (D-03)

| Behavior | Specification |
|----------|---------------|
| Open | Slide in from right, 400px width, 250ms ease-out, overlay on board |
| Close | Click outside, press Escape, or click close button |
| Expand | Button to expand to full modal (centered, 640px max-width) |
| Content | All card fields displayed, editable inline, "Abrir conversa no Chatwoot" link |

### Inline Stage Editing (D-07)

| Behavior | Specification |
|----------|---------------|
| Rename | Click on stage title transforms to input; Enter or blur saves; Escape cancels |
| Add stage | Click "+" column at board end; input auto-focuses; Enter creates; Escape removes |
| Delete stage | Context menu "Excluir estagio"; if cards > 0, shows ConfirmDialog with stage selector |
| Reorder stages | Drag column header to reorder (lower priority than card drag; can be phase v2 if complex) |

### Card Field Visibility (D-01, D-02)

| Behavior | Specification |
|----------|---------------|
| Default visible | Contact name, channel icon, relative time ("ha 2 dias") |
| Toggleable fields | Channel name (text), agent name, entry date (absolute), Chatwoot link icon |
| Toggle location | FieldVisibilityMenu popover triggered from BoardTopBar icon button |
| Persistence | Store in localStorage per user (no backend needed for v1) |

### Filters (D-09)

| Behavior | Specification |
|----------|---------------|
| Location | FilterBar in BoardTopBar, below page title |
| Agents dropdown | Fetched from JWT context or stages/cards data; multi-select |
| Channel dropdown | Derived from cards data; multi-select |
| Date range | Simple preset options: Hoje, Ultimos 7 dias, Ultimos 30 dias, Todos |
| "Atribuidos a mim" | Toggle button, active state uses `bg-n-brand/10 text-n-blue-11` (faded blue) |
| Clear | "Limpar filtros" link appears when any filter is active |
| Filtering | Client-side filtering on loaded cards (no server-side filter API needed for v1) |

## Technical Constraints

These are NOT design decisions but constraints that affect the design contract.

| Constraint | Impact |
|------------|--------|
| Tailwind-only styling (CLAUDE.md) | No custom CSS, no scoped styles, no inline styles |
| Composition API + `<script setup>` (CLAUDE.md) | All components use this pattern |
| i18n required (CLAUDE.md) | All copy goes through i18n, not hardcoded in templates |
| Snake_case API responses (Phase 2 decision) | Frontend maps snake_case to camelCase in API layer |
| Cursor pagination (Phase 2 decision) | Cards load progressively per column; show loading skeleton during fetch |
| JWT 1h expiry (Phase 2 decision) | Silent re-auth via Chatwoot token before expiry; no login screen in this phase |
| Dark mode support (D-13) | All colors via CSS vars; test both modes |
| Desktop-first (D-06) | Board scrolls horizontally on narrow viewports; no mobile-specific UX |
