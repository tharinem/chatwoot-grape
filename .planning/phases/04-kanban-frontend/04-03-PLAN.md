**CRITICAL CONTRACT -- cardMoved event shape:**
KanbanColumn emits `cardMoved` with shape `{ cardId: string, fromStageId: string, toStageId: string, newPosition: number }`.
KanbanBoard handles this event and calls `boardStore.moveCard(cardId, fromStageId, toStageId, newPosition)`.
Both components MUST use this exact shape -- mismatch will silently break drag-and-drop.

**KanbanBoard.vue:**
Horizontal flex container for all columns:
- Props: none (reads from store directly)
- Uses `useBoardStore()` to get `sortedStages` and `cardsByStage`
- Renders `<div class="flex gap-8 h-full items-start">` (xl=32px gap per UI-SPEC spacing)
- For each stage in `sortedStages`: render `<KanbanColumn :stage="stage" :cards="cardsByStage[stage.id] || []" />`
- After all columns, render a placeholder div for "Add Stage" button (Plan 04 implements `AddStageButton` -- for now render a `<div class="flex-shrink-0 w-[280px]" />` placeholder)
- Handle `cardMoved` event from columns: the event shape is `{ cardId: string, fromStageId: string, toStageId: string, newPosition: number }`. Call `boardStore.moveCard(cardId, fromStageId, toStageId, newPosition)`, then `showToast('success', t('toast.cardMoved', { stageName }))`; on error the store handles rollback and the error toast is shown from the store's catch block

**KanbanColumn.vue:**
Single stage column with drag-and-drop zone:
- Props: `stage: Stage`, `cards: Card[]`
- Column width: `w-[280px] flex-shrink-0` (fixed 280px per UI-SPEC)
- Column container: `bg-n-slate-2 rounded-xl flex flex-col max-h-full`
- **Column header:**
  - Color accent bar: `<div class="h-1 rounded-t-xl" :style="{ backgroundColor: stage.color || '#7B5EA7' }" />` (per D-12, configurable color, brand default)
  - Stage name: `<h3 class="text-base font-semibold text-n-slate-12 px-3 py-2">{{ stage.name }}</h3>` (Heading typography)
  - Card count badge: `<span class="text-xs text-n-slate-11">({{ cards.length }})</span>`
  - Right side of header: placeholder for "+" add card button and "..." menu (Plan 04 wires these)
- **Card list area (drag zone):**
  - Use `useDraggable` from `vue-draggable-plus` on a container ref
  - **CRITICAL:** Set `group: 'cards'` on EVERY column's useDraggable instance (same string) to enable cross-column drag per Research Pitfall 1
  - Set `animation: 200` for smooth card displacement per UI-SPEC (200ms ease-out)
  - Set `ghostClass: 'opacity-50'` for drag ghost
  - Set `dragClass: 'shadow-lg scale-[1.02]'` for lifted card per UI-SPEC (shadow-lg + scale 1.02)
  - Set `chosenClass: 'ring-2 ring-n-blue-7'` for selection highlight
  - Container: `<div ref="cardListRef" :data-stage-id="stage.id" class="flex flex-col gap-2 px-2 pb-2 min-h-[80px] overflow-y-auto">`
  - The `useDraggable` composable needs the container ref and a local reactive copy of cards. When `onEnd` fires:
    - Extract `cardId` from the moved element's dataset or the updated array
    - Extract `targetStageId` from `event.to.dataset.stageId`
    - Extract `newIndex` from `event.newIndex`
    - **Emit `cardMoved` event with exact shape:** `{ cardId: string, fromStageId: stage.id, toStageId: targetStageId, newPosition: newIndex }` -- this MUST match KanbanBoard's handler expectations
  - When the column has no cards and no drag is active, show `EmptyColumn`
- **Drop zone highlight per D-04:** When a card is dragged over this column, add visual feedback. SortableJS handles this via CSS class -- configure `dragoverBubble: false` and use Tailwind classes. The column container can detect drag-over via SortableJS `onMove` or by watching if `event.to` matches the current column.

**KanbanCard.vue:**
Draggable card displaying configurable fields per D-01:
- Props: `card: Card`, `visibleFields: string[]` (from uiStore)
- Container: `<div :data-card-id="card.id" class="bg-n-slate-1 rounded-lg border border-n-weak p-3 cursor-grab hover:shadow-md transition-shadow duration-150 active:cursor-grabbing">`
- **Always visible (per D-01 compact default):**
  - Contact name: `<p class="text-sm font-semibold text-n-slate-12 truncate">{{ card.contactName }}</p>`
- **Conditionally visible (based on `visibleFields` array):**
  - `channelType`: Show channel icon + text in `text-xs text-n-slate-11`. Use `i-lucide-message-square` for generic channel, or map known types (whatsapp -> `i-lucide-phone`, email -> `i-lucide-mail`, web -> `i-lucide-globe`)
  - `createdAt`: Show relative time using `date-fns` `formatDistanceToNow(new Date(card.createdAt), { addSuffix: true, locale: ptBR })`. Display as `text-xs text-n-slate-11`
  - `assigneeId`: Show agent name or ID (for v1, show "Agente #N" since we don't have agent names from the API -- Phase 5 may enhance this). `text-xs text-n-slate-11` with `i-lucide-user` icon
  - `conversationId` (Chatwoot link per KANB-05): Show `<a :href="chatwootConversationUrl" target="_blank" rel="noopener" class="text-xs text-n-blue-11 hover:text-n-blue-12 flex items-center gap-1"><span class="i-lucide-external-link w-3 h-3" />{{ t('slidePanel.openInChatwoot') }}</a>`. URL format: `${import.meta.env.VITE_CHATWOOT_URL}/app/accounts/${card.accountId}/conversations/${card.conversationId}`. Only show if `card.conversationId` is not null.
- **Card click handler (per D-03):** On click (not on drag), call `uiStore.openSlidePanel(card.id)`. Use a flag to distinguish click from drag-end (set a `isDragging` flag on dragstart, clear on dragend, ignore click if isDragging was true).
