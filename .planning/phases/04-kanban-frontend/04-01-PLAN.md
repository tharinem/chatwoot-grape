1. Create `kanban-frontend/` directory at project root.

2. Initialize with `npm create vite@latest kanban-frontend -- --template vue-ts` or manually create the scaffold files.

3. Install production dependencies:
   ```
   npm install vue@^3.5 vue-router@^5 pinia@^3 vue-i18n@^11 axios@^1.15 vue-draggable-plus@^0.6 @vueuse/core date-fns
   ```

4. Install dev dependencies:
   ```
   npm install -D tailwindcss@3 @tailwindcss/vite @egoist/tailwindcss-icons @iconify-json/lucide typescript@^5 vite@^8
   ```

5. Create `kanban-frontend/src/styles/colors.css` -- Copy ALL CSS custom properties from `app/javascript/dashboard/assets/scss/_next-colors.scss` into a `@layer base { :root { ... } .dark { ... } }` block. Convert SCSS to plain CSS. Include ALL color scales: `--slate-1` through `--slate-12`, `--blue-1` through `--blue-12`, `--ruby-1` through `--ruby-12`, `--amber-1` through `--amber-12`, `--teal-1` through `--teal-12`, `--brand`, and all functional tokens (`--background-color`, `--text-strong`, `--text-weak`, `--border-weak`, `--border-strong`, `--alpha-2`, etc.). Both `:root` (light) and `.dark` variants.

6. Create `kanban-frontend/tailwind.config.ts`:
   - `darkMode: 'class'`
   - Extend colors with `n` namespace mirroring `theme/colors.js` structure:
     - `n.slate.1` through `n.slate.12` as `rgb(var(--slate-1) / <alpha-value>)`
     - Same for `n.blue`, `n.ruby`, `n.amber`, `n.teal` (1-12 each)
     - `n.brand` as `#7B5EA7`
     - Functional tokens: `n.background`, `n.alpha.2`, `n.weak` (text), `n.strong` (text), `n.container`, etc.
   - Extend fontFamily: `sans: ['"DM Sans"', 'Inter', 'sans-serif']`
   - Configure `@egoist/tailwindcss-icons` plugin with `@iconify-json/lucide` collection
   - Content paths: `['./index.html', './src/**/*.{vue,ts,js}']`

7. Create `kanban-frontend/vite.config.ts`:
   - Import `@tailwindcss/vite` plugin
   - Set `resolve.alias`: `@` -> `./src`
   - Set `server.proxy` for `/api` -> `http://localhost:3001` (Kanban API dev server)

8. Create `kanban-frontend/src/main.ts`:
   - Import `./styles/colors.css`
   - Create and mount Vue app with Pinia, vue-router, vue-i18n
   - i18n config: `locale: 'pt-BR'`, `fallbackLocale: 'pt-BR'`, `messages: { 'pt-BR': ptBR }`

9. Create `kanban-frontend/src/App.vue`:
   - Minimal shell: `<RouterView />` with a wrapping div that has `class="min-h-screen bg-n-background text-n-slate-12 font-sans"`
   - Include a Toast teleport target: `<div id="toast-container" />`

10. Create `kanban-frontend/.env.example`:
    ```
    VITE_API_URL=http://localhost:3001/api/v1
    VITE_CHATWOOT_URL=http://localhost:3000
    ```

11. Create `kanban-frontend/.gitignore`: node_modules, dist, .env, *.local

12. Run `cd kanban-frontend && npm install` to verify clean install.

13. Run `cd kanban-frontend && npx vue-tsc --noEmit` to verify TypeScript compiles.
