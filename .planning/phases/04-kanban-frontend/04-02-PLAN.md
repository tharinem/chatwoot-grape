**API Client Layer:**

4. `src/api/client.ts`:
   - Create axios instance with `baseURL` from `import.meta.env.VITE_API_URL || '/api/v1'`
   - Request interceptor: attach `Authorization: Bearer ${token}` from localStorage key `kanban_jwt`
   - Response interceptor: on 401 where `!config._retry`, set `config._retry = true`, call `authStore.refreshToken()`, retry original request with new token. If retry fails, redirect to login.
   - Export `apiClient` instance.

**Pinia Stores:**

1. `src/stores/auth.ts` -- `useAuthStore`:
   - State: `jwt: string | null`, `chatwootToken: string | null`, `accountId: number | null`, `userId: number | null`, `role: string | null`, `isAuthenticated: boolean` (getter)
   - Actions:
     - `login(chatwootToken: string, accountId: number)` -- calls `authApi.exchangeToken`, stores JWT in state + localStorage `kanban_jwt`, decodes payload to extract user_id/account_id/role
     - `refreshToken()` -- re-calls exchangeToken with stored chatwootToken/accountId, updates JWT
     - `logout()` -- clears all state + localStorage
     - `initFromStorage()` -- on app mount, reads `kanban_jwt` and `kanban_chatwoot_token` from localStorage, validates not expired, sets state
   - JWT decode: use simple base64 atob on payload segment (no library needed for decode-only)

2. `src/stores/board.ts` -- `useBoardStore`:
   - State: `stages: Stage[]`, `cardsByStage: Record<string, Card[]>`, `loading: boolean`, `error: string | null`
   - Getters: `sortedStages` (by position), `allCards` (flat array of all cards), `cardCount` (total)
   - Actions:
     - `fetchBoard()` -- calls stagesApi.list(), then cardsApi.listByStage() for each stage, populates state
     - `moveCard(cardId: string, fromStageId: string, toStageId: string, newPosition: number)` -- optimistic update per D-05: snapshot current state, move card in local state immediately, call cardsApi.update with `{ stage_id: toStageId, position: newPosition }`, on error rollback from snapshot + trigger toast
     - `createCard(stageId: string, input: CreateCardInput)` -- calls cardsApi.create, adds to local state
     - `updateCard(id: string, input: UpdateCardInput)` -- calls cardsApi.update, updates in local state
     - `deleteCard(id: string)` -- calls cardsApi.remove, removes from local state
     - `createStage(input: CreateStageInput)` -- calls stagesApi.create, adds to local stages
     - `updateStage(id: string, input: UpdateStageInput)` -- calls stagesApi.update, updates in local state
     - `deleteStage(id: string)` -- calls stagesApi.remove, removes from stages (caller must move cards first per D-08)
     - `reorderStages(items: ReorderStageItem[])` -- calls stagesApi.reorder, updates local positions

3. `src/stores/ui.ts` -- `useUiStore`:
    - State: `visibleFields: string[]` (default: `['channelType', 'createdAt']` per D-01 compact default), `slidePanel: { isOpen: boolean, cardId: string | null }`, `activeFilters: { agentIds: number[], channelTypes: string[], datePreset: string | null, assignedToMe: boolean }`
    - Actions: `toggleField(field)`, `openSlidePanel(cardId)`, `closeSlidePanel()`, `setFilter(key, value)`, `clearFilters()`, `toggleAssignedToMe()`
    - Persist `visibleFields` to localStorage via `@vueuse/core useLocalStorage`
