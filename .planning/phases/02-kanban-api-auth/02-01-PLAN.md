1. **Chatwoot auth service** (`src/services/chatwoot-auth.ts`):
   - Define `ChatwootProfile` interface matching the verified Chatwoot response:
     ```typescript
     export interface ChatwootProfile {
       id: number;
       account_id: number;
       name: string;
       email: string;
       role: string;
       accounts: Array<{ id: number; name: string; role: string; status: string }>;
     }
     ```
   - Export `async function validateChatwootToken(token: string): Promise<ChatwootProfile | null>`
   - Implementation: `fetch(\`\${process.env.CHATWOOT_BASE_URL}/api/v1/profile\`, { headers: { api_access_token: token } })`
   - CRITICAL per research: header is `api_access_token`, NOT `Authorization: Bearer` (per AUTH-02)
   - Return null on non-ok response or catch error

2. **Default stage seeding** (`src/services/stage-seed.ts`):
   - Define `DEFAULT_STAGES` array per D-12:
     ```typescript
     const DEFAULT_STAGES = [
       { name: 'Prospecção', position: 1, color: '#3B82F6' },
       { name: 'Qualificado', position: 2, color: '#8B5CF6' },
       { name: 'Proposta', position: 3, color: '#F59E0B' },
       { name: 'Negociação', position: 4, color: '#EF4444' },
       { name: 'Fechado Ganho', position: 5, color: '#10B981' },
       { name: 'Perdido', position: 6, color: '#6B7280' },
     ];
     ```
   - Export `async function seedDefaultStages(prisma: PrismaClient, accountId: number): Promise<void>`
   - Check `prisma.stage.count({ where: { accountId } })` — if > 0, return early
   - Use `prisma.stage.createMany({ data: DEFAULT_STAGES.map(s => ({ ...s, accountId })), skipDuplicates: true })` (per D-11, prevents race condition per Pitfall 4)

3. **Auth Zod schemas** (`src/schemas/auth.ts`):
   ```typescript
   import { z } from 'zod';
   export const chatwootTokenSchema = z.object({
     chatwoot_token: z.string().min(1),
     account_id: z.number().int().positive(),
   });
   export const tokenResponseSchema = z.object({
     token: z.string(),
   });
   export type ChatwootTokenInput = z.infer<typeof chatwootTokenSchema>;
   ```

4. **Auth plugin** (`src/plugins/auth.ts`) — wrap in `fastify-plugin`:
   - Register `@fastify/jwt` with `secret: process.env.JWT_SECRET!`
   - Decorate fastify with `authenticate` method:
     ```typescript
     fastify.decorate('authenticate', async (request: FastifyRequest, reply: FastifyReply) => {
       try { await request.jwtVerify(); }
       catch (err) { reply.code(401).send({ type: 'https://kanban.api/errors/unauthorized', title: 'Unauthorized', status: 401, detail: 'Invalid or expired token' }); }
     });
     ```
   - Add TypeScript declaration merging for `FastifyInstance.authenticate` and `FastifyRequest.user` (with `user_id: number`, `account_id: number`, `role: string`)

5. **Tenant middleware** (`src/middleware/tenant.ts`):
   - Export a preHandler hook function that extracts `account_id` from `request.user` (set by jwtVerify) and makes it accessible
   - This is simply the pattern: after `authenticate` runs, `request.user.account_id` is available for all Prisma queries (per TENANT-01, AUTH-04)
   - No separate middleware needed if using `onRequest: [fastify.authenticate]` on routes — `request.user` is already populated. Export a helper type `JwtPayload = { user_id: number; account_id: number; role: string }` for route handlers to cast.

6. **Auth route** (`src/routes/v1/auth.ts`):
   - `POST /auth/chatwoot-token` — per D-08 under `/api/v1/` prefix
   - Use Zod schema `chatwootTokenSchema` for body validation
   - Flow (per AUTH-01, AUTH-02, AUTH-03):
     a. Extract `chatwoot_token` and `account_id` from body
     b. Call `validateChatwootToken(chatwoot_token)` — if null, return 401 via `problemResponse`
     c. Find `account_id` in `profile.accounts` array — if not found, return 403 (CRITICAL: don't trust top-level `account_id`, per Pitfall 1)
     d. Call `seedDefaultStages(prisma, account_id)` — per D-11, creates default stages on first auth
     e. Sign JWT: `fastify.jwt.sign({ user_id: profile.id, account_id, role: accountMembership.role }, { expiresIn: '1h' })` — per D-05, D-06
     f. Return `{ token }`
   - Export as Fastify plugin function

7. **Wire into app.ts:**
   - Import and register auth plugin, auth routes (prefixed `/api/v1`), ensure swagger plugin loads first
   - Register health route at root level (no prefix)
