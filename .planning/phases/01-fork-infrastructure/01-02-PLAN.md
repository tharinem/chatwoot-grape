  <name>Task 1: Deploy fork on Coolify via Docker Compose build pack</name>
  <files>N/A -- Coolify UI deployment</files>
  <action>
User must deploy the fork on Coolify. This cannot be automated -- Coolify deployment requires the web UI.

Pre-deployment preparation:
1. Export all environment variables from the CURRENT Chatwoot deployment on Coolify. Key variables to preserve: SECRET_KEY_BASE, FRONTEND_URL, POSTGRES_PASSWORD, REDIS_PASSWORD, POSTGRES_DB (chatwoot_production), POSTGRES_USER (chatwoot), RAILS_ENV=production, NODE_ENV=production, INSTALLATION_ENV=docker, plus any SMTP/storage/integration variables.
2. Check Coolify build timeout settings -- first build may take 15-30 minutes. Ensure build server has at least 4GB RAM (required by NODE_OPTIONS="--max-old-space-size=4096" in the Dockerfile).

Deploy steps:
3. In Coolify, create a new application using the "Docker Compose" build pack.
4. Point it to your fork's GitHub repository.
5. Set the branch to `custom`.
6. Set the Docker Compose file to `docker-compose.production.yaml`.
7. Add all environment variables from step 1.
8. Assign your domain to the `rails` service (do NOT add ports manually).
9. Deploy and wait for the build to complete.

Post-deploy database setup (first deploy only):
10. In Coolify's terminal for the rails service, run: bundle exec rails db:chatwoot_prepare
    (Or if migrating from existing DB, point POSTGRES_* vars to existing database)
  </action>

  <done>Chatwoot fork is deployed on Coolify, the rails and sidekiq services are running, and the login page is accessible via HTTPS at the assigned domain</done>
