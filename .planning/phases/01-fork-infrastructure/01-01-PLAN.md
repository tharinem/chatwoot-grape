<task type="auto">
  <name>Task 2: Create docker-compose.production.yaml (build from source)</name>
  <files>docker-compose.production.yaml</files>
  <read_first>
    - docker-compose.production.yaml (if exists -- this is the upstream file we are replacing)
    - docker/Dockerfile (to confirm the dockerfile path reference)
    - .dockerignore (to confirm .git is not excluded)
  </read_first>
  <action>
Create `docker-compose.production.yaml` at the repo root. This file replaces the upstream version that uses `image: chatwoot/chatwoot:latest` with a build-from-source version.

The file must contain:

1. A YAML anchor `x-base: &base` with:
   - `build:` block containing `context: .` and `dockerfile: docker/Dockerfile` and args `RAILS_ENV: production` and `NODE_ENV: production`
   - NO `image:` key (this is the key difference from upstream)
   - `env_file: .env`
   - `volumes:` mapping `storage_data:/app/storage`
   - `restart: always`

2. Four services:
   - `rails`: extends `*base`, depends_on postgres and redis, environment sets `NODE_ENV=production`, `RAILS_ENV=production`, `INSTALLATION_ENV=docker`
   - `sidekiq`: extends `*base`, depends_on postgres and redis, command `['bundle', 'exec', 'sidekiq', '-C', 'config/sidekiq.yml']`
   - `postgres`: image `pgvector/pgvector:pg16`, restart always, volume `postgres_data:/var/lib/postgresql/data`, environment `POSTGRES_DB=chatwoot_production`, `POSTGRES_USER=chatwoot`, `POSTGRES_PASSWORD=${POSTGRES_PASSWORD:?required}`
   - `redis`: image `redis:7-alpine`, restart always, command `['redis-server', '--requirepass', '${REDIS_PASSWORD:?required}']`, volume `redis_data:/data`

3. Three named volumes: `storage_data`, `postgres_data`, `redis_data`

CRITICAL: Do NOT add any `ports:` mappings to any service. Coolify's Traefik proxy handles external routing via domain assignment in the Coolify UI.

Add a comment header at the top:
```
# Chatwoot Fork - Production Docker Compose
# Modified from upstream to build from source instead of pulling pre-built image.
# See UPSTREAM_DIFF.md for fork divergence documentation.
# Original: https://github.com/chatwoot/chatwoot/blob/develop/docker-compose.production.yaml
```
  </action>
  <verify>
    <automated>grep -q "build:" docker-compose.production.yaml && grep -q "dockerfile: docker/Dockerfile" docker-compose.production.yaml && grep -q "pgvector/pgvector:pg16" docker-compose.production.yaml && grep -q "redis:7-alpine" docker-compose.production.yaml && ! grep -q "ports:" docker-compose.production.yaml && ! grep -q "image: chatwoot" docker-compose.production.yaml && echo "PASS" || echo "FAIL"</automated>
  </verify>
  <acceptance_criteria>
