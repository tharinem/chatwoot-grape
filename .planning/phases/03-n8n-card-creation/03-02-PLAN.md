2. Create `kanban-api/src/routes/v1/api-keys.ts` (per D-02):
   - Default export async function `apiKeyRoutes(fastify: FastifyInstance)`.
   - `POST /api-keys` — Generate new API key (admin only):
     a. `onRequest: [fastify.authenticate]` (JWT auth, not API key auth).
     b. Check role: `const { account_id, role } = request.user as JwtPayload`. If role !== 'administrator', return 403 via `problemResponse`.
     c. Revoke existing keys: `await prisma.apiKey.updateMany({ where: { accountId: account_id, revokedAt: null }, data: { revokedAt: new Date() } })`.
     d. Generate new: `const { raw, prefix, hash, salt } = generateApiKey()`.
     e. Create: `const record = await prisma.apiKey.create({ data: { accountId: account_id, keyHash: hash, salt, prefix } })`.
     f. Response schema: `createApiKeyResponseSchema`. Return `{ id: record.id, raw_key: raw, prefix }`.
   - `DELETE /api-keys/:id` — Revoke specific key (admin only):
     a. `onRequest: [fastify.authenticate]`.
     b. Check admin role.
     c. Find key: `prisma.apiKey.findFirst({ where: { id, accountId: account_id, revokedAt: null } })`. If not found, 404.
     d. Revoke: `prisma.apiKey.update({ where: { id }, data: { revokedAt: new Date() } })`.
     e. Return 204.
